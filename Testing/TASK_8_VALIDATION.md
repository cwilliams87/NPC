```python
class AgentState(TypedDict, total=False):
    npc_id: str
    backstory_summary: str
    personality_weights: Dict[str, float]

    long_term_memory_ids: List[str]

    emotional_state: Dict[str, float]
    current_goal: str
    world_context: Dict
```

### Design Decisions

#### Why TypedDict instead of Pydantic BaseModel?
- **LangGraph Compatibility**: LangGraph StateGraph expects TypedDict
- **Performance**: TypedDict has lower overhead than Pydantic
- **Flexibility**: TypedDict allows partial updates (total=False)
- **Separation**: Pydantic for API boundaries, TypedDict for internal state

#### Why total=False?
- Allows partial state updates during workflow execution
- Nodes can update only relevant fields
- Supports incremental state building
- Maintains type safety with optional fields

#### Why Helper Functions?
- Encapsulates common operations
- Reduces code duplication
- Provides consistent behavior
- Easier to test and maintain
- Clear API for state manipulation
